# Demo pública del visualizador de reconstrucción

Visor interactivo con imágenes sintéticas para probar comparaciones, filtros y exportación de métricas. Las imágenes son dibujos procedurales; las cifras no son resultados del piloto. El archivo HTML es autónomo.

Para publicar: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. El punto de entrada es `index.html`.
